A fitness tracker app I created with Laravel, PHP, MySQL, tailwind and a few other technologies, inside docker containers. It allows the user to enter weight goals and see things like their BMI and body fat percentage. There is also a food lookup which allows the user to lookup nutrition data for certain foods and add the data to their daily nutrition.

Want to check out the application live? Just visit https://01a1a32a-c0a9-7c3b-af3e-4ad9fca9c6dd-80.eur-1.aiven.app/login and create a account, there's currently no email validation so you can just use a dummy email for registration.
